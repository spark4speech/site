# SPARK website

The public marketing website for SPARK: Speech Personalized Access Resource Kit.

## Local development

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`. Before publishing a content change, run:

```bash
npm run lint
npm run build
```

## Public services

- Marketing site: <https://www.spark4speech.com>
- SPARK web app: <https://web.spark4speech.com>
- Support: <https://web.spark4speech.com/support>
- Privacy: <https://web.spark4speech.com/privacy>
- Terms: <https://web.spark4speech.com/terms>
- Licenses: <https://web.spark4speech.com/licenses>

The website does not collect newsletter signups, require accounts, or include analytics. If that changes, update the published privacy disclosures before deployment.

## Content rules

- Describe only features available in the current production app.
- Do not claim clinical outcomes without appropriate evidence.
- Do not describe SPARK as open source, nonprofit, or fiscally sponsored.
- Mark unreleased native apps as coming soon until their store pages are live.
- Use approved, current product screenshots and verify every external link.
